# Lumorphia のデザインと素材

Lumorphia の公式サイトのデザイン試作。ユーザー提供の既存ロゴを軸に、青紫寄りの白、落ち着いた藍色、淡い虹色の光を組み合わせる。余白と揃った配置で、ブランド紹介と各サービスへの入口を作る。

## 開く

開発・配信の手順は [README](../README.md) を参照。
右上のアイコンでライト／ダークを切り替える。`?theme=dark` でもダークから表示できる。
720px 以下ではスマートフォン用の配置になる。

## 構成

- 導入：既存のロゴを主役に、淡い光と軌道の輪郭を添える。
- サービス：Prismtone の写真編集・ミラプリ共有、準備中の Scenote、タイムラインのコールの CueLine の紹介。
- アカウント：共通プロフィールとログインの入口。

採用されたトップページのデザイン。包括的なブランド規定はまだ作成していない。
ヘッダーとフッターは提供アイコンとセリフ体によるコンパクトな組み合わせ。冒頭は提供された文字付きロゴをそのまま表示する。
ダークでは文字付きロゴの背後に明るい光を置き、元画像の文字色を変更せずに見やすくする。
外部リンクはサービスのドメインと GitHub に向けている。公開状態やリンク先の内容はこの試作では検証していない。
Accounts の機能紹介は計画・実装資料に基づくもので、本番公開を意味しない。
本番用HTMLから試作ラベルと `noindex` を外した。公開はまだ行っていない。

## 素材

既存ロゴは `previews/ref/` のユーザー提供 PNG を加工せずコピーしたもの。

- `assets/lumorphia-icon.png`：`7c68617e-c21d-4c2f-bdbc-7dbad7c87f85.png`。
- `assets/lumorphia-logo.png`：`9a739d48-73bf-44b4-ac73-b63d51b8436d.png`。

Prismtone は実アプリの `../prismtone/apps/app/web/assets/brand/` から文字のみ版 SVG をそのままコピーしたもの。
`assets/prismtone-light-wordmark.svg` / `assets/prismtone-dark-wordmark.svg` を表示テーマに応じて切り替える。
元の文字色・青い結晶・縦横比を保ち、書体のライセンスを `assets/Cormorant-OFL.txt` に同梱している。

`assets/prismtone-photo.webp` は、既存のユーザー提供素材を試作用に再利用したもの。
元：`../prismtone/docs/design/previews/editorial/assets/shot-1.webp`。
出典記録：同ディレクトリの `../photos.json`、元ファイル `ffxiv_20240628_203136_914.png`。
掲載ゲーム画像：© SQUARE ENIX。画像全体を表示し、元の縦横比と画像内の著作権表示を保つ。
Scenote の風景は CSS によるイメージ図で、ゲーム画像や実サービスの画面ではない。
CueLine のタイムラインの図も CSS によるイメージ図で、実サービスの画面ではない。

### FFXIV の権利表記

2026-10-10 に公式の[ファイナルファンタジーXIV 著作物利用条件](https://support.jp.square-enix.com/rule.php?id=5381&tag=authc)を確認した（2026-09-16 改訂）。
「3-1. 画像・テキスト・動画素材のインターネット上での利用」(2) に従い、フッターに `© SQUARE ENIX` を改行せず表示する。
同項では、複数の著作物を掲載する場合もページ全体で1箇所の表記を認め、スクリーンショット内の権利表記はそのまま利用してよいと定めている。
非公式サイトである旨は、この権利表記とは別の自主的な説明として残す。
今回の確認・変更はフッターの権利表記に関するもので、サイト全体の利用条件への適合を確認したものではない。
